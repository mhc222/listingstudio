# Reel music

Drop royalty-free `.mp3` tracks here — the reel builder's music picker lists
this directory. Keep filenames short (they show as the picker label, extension
stripped, dashes/underscores become spaces).

Sources with reel-safe licenses: pixabay.com/music, incompetech.com (CC-BY),
YouTube Audio Library. Tracks are bundled into the deploy (next.config
outputFileTracingIncludes), so keep it to a handful of files.
