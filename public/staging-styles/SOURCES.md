# Staging style preview sources

These locally bundled photographs are visual examples for the Stage picker. The style name remains the authoritative control label. The previews are never sent to fal.ai, Anthropic, or another model as generation references.

All photographs were downloaded and cropped on 2026-09-01 under the [Pexels license](https://www.pexels.com/license/). Pexels' contributor policy states that [generative-AI photos and videos cannot be uploaded](https://help.pexels.com/hc/en-us/articles/27453505326873-Can-I-upload-generative-AI-photos-and-videos-to-Pexels). Files are served locally; the application makes no runtime request to Pexels.
